# Описание работы программы 
## Входные данные (Что получаем на ввод)
Программа ожидает, что на вход поступят три файла в формате `.xlsx` (таблицы Excel):
 `Сводный_прошлый_год.xlsx`
 `Осень.xlsx`
 `Весна.xlsx`
Скрипт ожидает, что эти исходные файлы будут лежать в отдельной папке `data`, чтобы не засорять корневую директорию проекта. В самих таблицах программа будет искать определенные столбцы: **Название**, **Группа**, **Вид** и **Нагрузка**.

## Выходные данные (Что получаем на вывод)
Программа ничего не сохраняет в новые файлы, весь результат работы выводится текстом прямо в консоль. На экран печатается:
 Сообщение о создании папки `data` и просьба закинуть туда исходники (если папки изначально не было).
 Базовая статистика при загрузке каждого файла: количество строк, количество столбцов и их названия.
 Списки уникальных дисциплин, уникальных студенческих групп и видов учебной нагрузки (если нужные колонки найдены).
 Общая сумма по столбцу "Нагрузка".
 Первые 5 строк каждой загруженной таблицы, чтобы можно было глазами проверить структуру данных.
 Уведомления об ошибках (если нужный файл не найден или поврежден).

## Как работает код
Скрипт написан с использованием объектно-ориентированного подхода (ООП) и использует библиотеку `pandas` для анализа данных. Код работает в несколько этапов:
### 1. Подготовка директории
В самом начале скрипт подключает стандартный модуль `os`. Он проверяет, существует ли на компьютере папка с названием `data`. Если ее нет, код сам создает эту папку командой `os.makedirs` и просит пользователя положить в нее нужные файлы перед нормальным запуском. После этого через `os.chdir()` рабочая директория меняется на папку `data`, чтобы дальше Питон искал файлы только там.
### 2. Создание класса
Объявляется класс `WorkloadLoader`, в котором хранится вся логика. При запуске (в методе `__init__`) создаются три пустые переменные, куда позже запишутся наши таблицы.
### 3. Загрузка данных
Метод `load_file` принимает путь к таблице и пробует прочитать ее с помощью `pd.read_excel()`. Сразу после чтения функция выводит размер таблицы и список ее колонок. Все обернуто в блок `try/except`, чтобы при отсутствии файла скрипт не вылетал с критической ошибкой, а просто написал текст об ошибке загрузки.
### 4. Анализ данных
Метод `analyze_data` берет уже загруженную таблицу и по очереди проверяет наличие в ней определенных столбцов. Если столбец "Название", "Группа" или "Вид" есть, программа удаляет пустые значения через `dropna()`, находит все уникальные записи через `unique()` и выводит их в консоль. Для колонки "Нагрузка" вместо уникальных значений считается общая сумма через метод `.sum()`. В конце вызывается метод `.head()`, чтобы показать первые пять строчек таблицы.
### 5. Сборка
Функция `main` — это точка входа в программу. Здесь создается объект нашего класса. Сначала вызывается метод `load_all_files`, который по очереди загружает три файла Excel. Затем запускается метод `show_information`, который прогоняет каждую из трех сохраненных таблиц через наш анализатор.
### 6. Запуск
Конструкция `if __name__ == "__main__":` в самом конце нужна для того, чтобы функция `main()` сработала только в том случае, если мы запустили именно этот файл напрямую, а не импортировали его как модуль куда-то еще.
